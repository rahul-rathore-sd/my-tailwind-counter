# 🚀 React Counter App

A simple React project built using the **useState Hook** to create a counter with conditional logic.

---

## ✨ Features

- 🔢 Increment & Decrement Counter
- 🧠 Conditional Logic
- ⚛️ Built with React Hooks
- ⚡ Fast development with Vite

---
